# Anyway Proxy

Бета **0.2.2**. Пакеты для ImmortalWrt 25.12.x (`rockchip/armv8`).

- [Releases](https://github.com/raaad1on/anyway-releases/releases)
- Каталог [`packages/`](./packages) — `.apk` текущей беты

## Установка

```sh
apk add --allow-untrusted ./anyway-xray-*.apk ./luci-app-anyway-proxy-*.apk
```

В LuCI укажите URL подписки (Xray JSON или список URI), обновите её и выберите профиль.
